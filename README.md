# Conceito Joias 18K

Site vitrine da Conceito Joias 18K (correntes e joias de ouro 18K).

- Instagram: https://www.instagram.com/_conceitojoias.18k/
- WhatsApp: https://wa.me/5511914390703

O site é um único arquivo, `index.html`, com as fotos já incluídas. Não precisa de instalação nem de build.

## Publicar no GitHub Pages
1. Suba o `index.html` na raiz do repositório (branch `main`).
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Aguarde 1 a 2 minutos. O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
